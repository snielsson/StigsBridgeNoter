# Indmeldinger og oplysningsdobling

Når modstanderne har åbnet — kan dit makkerpar stadig kæmpe om kontrakten.

## Direkte indmelding

| Indmelding | Krav | Viser |
|------------|------|-------|
| **1 i kulør** | 12+ HP, 5+ kort | Naturlig, 5-korts+ |
| **1NT** | 15–18 HP, afbalanceret, stopper i mods. kulør | Sanstrumf-indmelding |
| **Dobling (X)** | 12+ HP, 4-4 i de umeldte kulører | Oplysningsdobling |
| **2 i kulør** (spring) | 14+ HP, 6+ kort | Stærk indmelding |
| **2NT** | 20–21 HP, afbalanceret, stoppere | Stærk NT-indmelding |
| **2 i kulør** (jump-spærre, eks. 1♥–2♠) | 5–10 HP, 6+ kort | Spærre-indmelding |

## Sæde-indmelding (balancering)

Når alle har passet rundt og det er din tur til at "vække auktionen":
**10–11 HP og en god kulør er nok** — det er "gratis" at indmelde.

## Beslutningstræ

```
Modstander åbner 1♥
│
├─ 5+ ♠?              → 1♠   (12+ HP)
├─ 5+ ♣ eller ♦?      → 2♣ / 2♦   (14+ HP, kræver mere på 2-trin)
├─ Afbalanceret 15–18 HP, ♥-stopper?   → 1NT
├─ 4-4 i ♠+♣ eller ♠+♦, 12+ HP?        → Dobling (oplysning)
└─ Ellers                              → PAS
```

## Oplysningsdobling (takeout double)

En **konventionel** dobling der siger: "Jeg har styrke i de umeldte kulører — vælg din bedste, makker."

### Krav

1. Modstander har meldt — du dobler umiddelbart
2. **Din makker har endnu ikke meldt**
3. Du dobler på de første 3 niveauer
4. 12+ HP og 4-4 (eller bedre) i de tre umeldte kulører

### Hvad doblingen viser

| Modstander åbnede | Dobler viser 4+ i |
|-------------------|--------------------|
| 1♣ | ♠ ♥ ♦ |
| 1♦ | ♠ ♥ ♣ |
| 1♥ | ♠ ♦ ♣ (særlig fokus på ♠) |
| 1♠ | ♥ ♦ ♣ |

### Makkerens svar på oplysningsdobling

> **Du SKAL melde** — også med 0 HP. Det er pointen.

```
Partner doblede 1♥ (viser ♠ ♦ ♣)
│
├─ 0–7 HP    → meld laveste 4-korts kulør
├─ 8–10 HP   → meld bedste kulør på 2-trin
├─ 11–12 HP  → spring i bedste kulør (invitation)
└─ 13+ HP    → spring til parti / 2NT
```

## Hvornår er en dobling STRAFFEDOBLING (ikke oplysning)?

- Makker har allerede meldt en kulør
- Dobleren har allerede meldt en kulør
- Doblingen kommer på 4-trin eller højere
- Doblingen kommer på en NT-melding (typisk straf)
