# Blackwood / RKC 1430 (4NT essespørger)

Bruges kun når **fit er etableret** og slem undersøges.

## Hvornår byde 4NT?

1. Fit etableret eller NT-kontrakt aftalt
2. Makkerparret har sandsynligvis 33+ HP tilsammen
3. Du er usikker på om makker har de nødvendige esser

## Klassisk Blackwood (4 esser)

```
4NT spørger: "Hvor mange esser har du?"
       │
       ├─ 5♣  → 0 eller 4 esser
       ├─ 5♦  → 1 es
       ├─ 5♥  → 2 esser
       └─ 5♠  → 3 esser
```

## RKC 1430 (Roman Key Card) — bruges i Ny Nordisk

**Key cards** = de 4 esser **+** trumfkongens K (5 i alt).

```
4NT spørger: "Hvor mange key cards?"
       │
       ├─ 5♣  → 1 eller 4 key cards
       ├─ 5♦  → 0 eller 3 key cards
       ├─ 5♥  → 2 key cards, INGEN trumfdame
       └─ 5♠  → 2 key cards + trumfdame
```

> Husketal: **1430** = 1 eller 4 (5♣), 3 eller 0 (5♦).

## Beslutning efter svaret

```
Du har spurgt 4NT. Makker svarer 5♦ (= 1 key card)
│
├─ Du har 3 key cards → tilsammen 4 → 6NT eller 6 i kuløren
└─ Du har 2 key cards → tilsammen 3 → STOP på 5-trin
```

## Spørg om trumfdame (efter Blackwood-svar)

Efter et 5♣/5♦-svar (uden klar 2 key cards-info), kan næste melding (ikke 5 i trumfkuløren) spørge om trumfdamen:
- Svar: **5 i trumfkulør** = ingen trumfdame
- Svar: **6 i kuløren** = jeg har trumfdamen

## Eksempel-auktion

```
1♥  —  2NT (Jacoby, 14 HP, 4♥)
4♥  —  4NT (RKC)
5♣  —  6♥
```
- 1♥: 15 HP, 5+ ♥
- 2NT: 14 HP + 4-korts ♥ — forcing til parti
- 4♥: minimum jævn hånd
- 4NT: spørg om key cards (29+ HP, slem mulig)
- 5♣: 1 eller 4 key cards (her: 1, fordi minimum åbning)
- 6♥: lilleslem (2 esser tilsammen + 9-korts fit + 29 HP)

## OBS

- 4NT er **ikke** Blackwood hvis det er en naturlig kvantitativ invitation (1NT–4NT eller 2NT–4NT) — der spørger 4NT om åbner skal byde 6NT.
- Kun naturlig 4NT efter en farveaftale = Blackwood/RKC.
