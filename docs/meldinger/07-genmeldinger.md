# Genmeldinger (åbners 2. melding)

Efter svarers 1. melding skal åbner præcisere sin styrke.

## Efter 1-major → svarer 1NT (6–10 HP, ingen fit)

```
1♥ — 1NT
       │
       ├─ 13–15 HP, ensfarvet (5+ ♥)        → 2♥   (gentagelse, svag)
       ├─ 13–15 HP, 4+ ♣ eller ♦             → 2♣ / 2♦  (ny kulør, non-forc.)
       ├─ 16–18 HP, 5+ ♥                     → 3♥   (invitation)
       └─ 19–20 HP                           → 4♥   (parti direkte)
```

## Efter 1-major → svarer ny kulør (forcing!)

Eksempel: 1♥ — 1♠

```
1♥ — 1♠
       │
       ├─ 4+ ♠ (fit!), 13–15 HP              → 2♠   (støtte, non-forc.)
       ├─ 4+ ♠ (fit!), 16–18 HP              → 3♠   (invitation)
       ├─ 4+ ♠ (fit!), 19–20 HP              → 4♠   (parti)
       │
       ├─ Ingen ♠-fit, 13–15 HP, 6+ ♥        → 2♥   (gentagelse)
       ├─ Ingen ♠-fit, 16–18 HP, 6+ ♥        → 3♥   (invitation, jump)
       │
       ├─ 13–14 HP, balanceret               → 1NT  (ingen fit, jævn)
       ├─ 18–19 HP, balanceret               → 2NT  (jump, invitation)
       │
       ├─ 17+ HP, 4+ ♣/♦                     → REVERSE (2♣/2♦) — forcing
       └─ 13–15 HP, 4+ ♣/♦ (lavere kulør)    → 2♣/2♦ (non-forc. ny kulør)
```

## Reverse (omvending)

Åbners gensvar i ny kulør på 2-trin der er **højere** end åbningskuløren.

| Auktion | Reverse? |
|---------|----------|
| 1♣ — 1♥ — 2♦ | NEJ (lavere) |
| 1♣ — 1♥ — 2♠ | **JA** (17+ HP, 5+♣ + 4+♠) |
| 1♦ — 1♠ — 2♥ | **JA** (17+ HP, 5+♦ + 4+♥) |
| 1♦ — 1♥ — 2♣ | NEJ (lavere) |

> **Reverse = Rigtig Styrke.** 17+ HP og forcing. Første kulør altid længere end den anden.

## Efter 1-minor → svarer 1-major

```
1♣ — 1♥
       │
       ├─ 4+ ♥ (fit!), 13–15 HP              → 2♥
       ├─ 4+ ♥ (fit!), 16–18 HP              → 3♥
       ├─ 4+ ♥ (fit!), 19+ HP                → 4♥
       │
       ├─ Ingen fit, 13–15 HP, 4+ ♠          → 1♠ (vis 4-korts spar)
       ├─ Ingen fit, 13–14 HP, balanceret    → 1NT
       ├─ Ingen fit, 18–19 HP, balanceret    → 2NT
       └─ Ingen fit, 13–15 HP, 6+ ♣          → 2♣ (gentagelse)
```

## HP-zoner for åbners gensvar

| Zone | HP | Karakter af gensvar |
|------|----|--------------------|
| Minimum | 13–15 | Simpelt 2-trins gensvar (gentagelse, billig ny kulør, simpel støtte, 1NT) |
| Mellem | 16–18 | Jump (3-trinsgensvar, jump-støtte, 2NT) |
| Maksimum | 19–20 | Parti direkte (4-major, 3NT) |
| Ekstra | 17+ | Reverse hvis fordelingen passer |
