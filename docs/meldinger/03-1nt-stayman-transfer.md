# Svar på 1NT — Stayman & Jacoby Transfer

Åbner viste 15–17 HP, afbalanceret. Alt fra svarer er nu **konventionelt**.

## Beslutningstræ

```
Makker åbnede 1NT (15–17 HP)
│
├─ 0–7 HP                                  → PAS
│
├─ 4+ kort i 5-korts major (♥ eller ♠):
│   └─ Brug Jacoby Transfer
│       ├─ 5+ ♥  → 2♦  (åbner SKAL melde 2♥)
│       └─ 5+ ♠  → 2♥  (åbner SKAL melde 2♠)
│
├─ 8+ HP + 4-korts major (uden 5-korts):
│   └─ 2♣ Stayman ("har du 4-korts major?")
│
├─ 8–9 HP, balanceret, ingen major          → 2NT  (invitation)
├─ 10–15 HP, balanceret, ingen major        → 3NT  (parti direkte)
│
├─ 16+ HP                                   → 4NT (kvant. inv. til lilleslem)
└─ 17+ HP                                   → 6NT (lilleslem direkte)
```

## Stayman (2♣ over 1NT)

**Krav:** 8+ HP + mindst én 4-korts major.

```
1NT — 2♣ (Stayman)
       │
       ├─ 2♦ = INGEN 4-korts major
       │       Svarer: 2NT (inv.) eller 3NT (parti)
       │
       ├─ 2♥ = 4 hjerter (måske også 4 spar)
       │       Svarer m. 4♥: → 4♥ (parti)
       │       Svarer kun 4♠: → 3NT
       │
       └─ 2♠ = 4 spar (men IKKE 4 hjerter)
               Svarer m. 4♠: → 4♠ (parti)
               Svarer kun 4♥: → 3NT
```

## Jacoby Transfer

| Svarer melder | Betydning | Åbner SKAL melde |
|---------------|-----------|------------------|
| 2♦ | 5+ hjerter | **2♥** |
| 2♥ | 5+ spar | **2♠** |

```
1NT — 2♦ (transfer til ♥)
1NT — 2♥ (åbner tvunget)
       │
       ├─ Svarer passer       → 2♥ slutkontrakt (svag)
       ├─ Svarer 3♥           → invitation (5-korts + 8–9 HP)
       ├─ Svarer 4♥           → parti (6+ ♥ eller 5+ + 10+ HP)
       └─ Svarer 3NT          → makker vælger 3NT eller 4♥
```

## Stayman eller Transfer?

| Situation | Vælg |
|-----------|------|
| 5-korts major | **Transfer** |
| 4-korts major (én eller to) | **Stayman** |
| Ingen major, 8–9 HP | 2NT |
| Ingen major, 10+ HP | 3NT |

## Gensvar på 2NT-invitation

```
1NT — 2NT (8–9 HP, invitation)
       │
       ├─ Åbner 15 HP (min)   → PAS
       └─ Åbner 16–17 HP      → 3NT
```

## Hvad makker har efter 1NT

| Svarers HP | Kombineret | Svar |
|-----------|-----------|------|
| 0–7 | 15–24 | PAS |
| 8–9 | 23–26 | 2NT (inv.) |
| 10–15 | 25–32 | 3NT |
| 16+ | 31+ | Slemundersøgelse (4NT) |
