# Svar på åbning 1 i farve

## Beslutningstræ

```
Makker åbnede 1 i farve
│
├─ 0–5 HP                                  → PAS
│
├─ Fit (3+ kort i makkers kulør):
│   ├─ 6–10 HP + 3-korts                   → 2 i kuløren  (simpel støtte)
│   ├─ 6–10 HP + 5+ kort, fordelt          → 4 i kuløren  (præemptiv parti)
│   ├─ 10–12 HP + 4 kort                   → 3 i kuløren  (limit raise, invitation)
│   ├─ 13–15 HP + 4 kort                   → 4 i kuløren  (parti direkte)
│   └─ 13+ HP + 4+ kort (major)            → 2NT  (Jacoby, forcing)
│
├─ Ingen fit, ny kulør:
│   ├─ 6+ HP + 4+ ny kulør på 1-trin       → ny kulør  (forcing!)
│   └─ 10+ HP + 4+ ny kulør på 2-trin      → ny kulør  (forcing, kræver mere)
│
└─ Ingen fit, ingen ny kulør (NT):
    ├─ 6–10 HP                             → 1NT  (negativ, non-forcing)
    ├─ 11–12 HP                            → 2NT  (invitation)
    └─ 13–15 HP                            → 3NT  (parti direkte)
```

## Svartabel — makker åbnede 1♥

| Svar | HP | Hvad det viser |
|------|----|----------------|
| PAS | 0–5 | For svagt til svar |
| 1♠ | 6+ | 4+ spar, **forcing** |
| 1NT | 6–10 | Ingen fit, ingen ny kulør |
| 2♣ / 2♦ | 10+ | 4+ i kuløren, **forcing** |
| 2♥ | 6–10 | 3+ hjerter, simpel støtte |
| 2NT | 11–12 | Balanceret, invitation |
| 3♥ | 10–12 | 4+ hjerter, limit raise (invitation) |
| 3NT | 13–15 | Balanceret, direkte parti |
| 4♥ | 6–10 | 5+ hjerter + svag fordelt — blokerende parti |
| 2NT (Jacoby) | 13+ | 4+ hjerter, forcing til parti |

## Forcing vs. non-forcing

- **Ny kulør fra svarer = forcing** — åbner SKAL melde videre.
- **NT-svar og simpel støtte = non-forcing** — åbner kan passe.
- **Spring-støtte (3♥ over 1♥) = invitation, non-forcing.**

## Huskeregler

1. **Søg fit i major først** (8-korts fit slår alt).
2. **Med fit:** vis HP og længde via støtteniveau.
3. **Uden fit, men 4+ ny kulør:** ny kulør slår NT-svar.
4. **Spring (jump) = invitation**, ikke forcing (undtagen Jacoby 2NT).
