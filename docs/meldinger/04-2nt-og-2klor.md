# Svar på 2NT og 2♣

## Svar på 2NT (åbner viser 20–21 HP, afbalanceret)

| Svarers HP | Kombineret | Svar |
|-----------|-----------|------|
| 0–3 | 20–24 | **PAS** |
| 4–9 | 24–30 | **3NT** (parti) |
| 4+ med 4-korts major | – | **3♣ Stayman** |
| 4+ med 5-korts major | – | **3♦** (transfer ♥) / **3♥** (transfer ♠) |
| 10–12 | 30–33 | **4NT** (kvantitativ — inv. til lilleslem) |
| 13+ | 33+ | **6NT** direkte |

### Stayman over 2NT

```
2NT — 3♣ (Stayman)
       │
       ├─ 3♦ = ingen 4-korts major
       ├─ 3♥ = 4 hjerter
       └─ 3♠ = 4 spar
```

### Transfer over 2NT

| Svarer | Betydning | Åbner |
|--------|-----------|-------|
| 3♦ | 5+ ♥ | **3♥** |
| 3♥ | 5+ ♠ | **3♠** |

### 4NT er kvantitativ (ikke Blackwood)

10+ HP over 2NT → byd 4NT.
- Åbner med **20 HP (min)** → PAS
- Åbner med **21 HP (max)** → 6NT

## Svar på 2♣ (kunstig stærk, 22+ HP, forcing til parti)

> **Du SKAL svare** — selv med 0 HP.

| Svar | HP | Betydning |
|------|----|-----------|
| **2♦** | 0–7 | "Waiting bid" — kunstig, ingen info |
| 2♥ | 8+ | 5+ hjerter, naturlig |
| 2♠ | 8+ | 5+ spar, naturlig |
| 2NT | 8–10 | Afbalanceret, ingen 5-korts |
| 3♣ / 3♦ | 8+ | 5+ kuløren, naturlig |

### Åbnerens 2. melding efter 2♣ — 2♦

```
2♣ — 2♦ (waiting)
       │
       ├─ 22–23 HP afbalanceret      → 2NT
       │   └─ Svarer: PAS (0–2), 3NT (3+)
       │       (Stayman/transfer på 3-trinnet kan bruges)
       │
       ├─ 5+ ♥                        → 2♥  (forcing til parti)
       ├─ 5+ ♠                        → 2♠  (forcing til parti)
       ├─ 5+ ♦                        → 3♦
       └─ 5+ ♣                        → 3♣
```

> **Forcing til parti:** Efter 2♣–2♦ må ingen passe under partiniveau (4-major, 3NT, 5-minor).

### Eksempel

| Du har efter makker åbnede 2♣ | Svar |
|--------------------------------|------|
| ♠96 ♥852 ♦J743 ♣9632 (0 HP) | **2♦** (waiting) |
| ♠KQ872 ♥73 ♦K84 ♣952 (9 HP, 5♠) | **2♠** |
| ♠K72 ♥Q85 ♦K942 ♣J64 (9 HP, jævn) | **2NT** |
