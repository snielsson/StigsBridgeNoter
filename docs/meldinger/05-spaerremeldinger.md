# Spærremeldinger (præemptive åbninger)

Svag hånd, lang kulør. Formål: stjæl melderum fra modstanderne.

## Krav

- Lang kulør: 6 (niveau 2), 7 (niveau 3), 8 (niveau 4)
- 5–10 HP (svag hånd)
- Mindst 2 af AKQ i kuløren (på 3-trin og højere)
- Ingen sidekulør der er for stærk

**Tommelfingerregel:** Antal trumf − 3 = spærreniveau.

## Tabel

| Åbning | Kortlængde | HP |
|--------|-----------|-----|
| 2♦ | 6 | 5–10 |
| 2♥ | 6 | 5–10 |
| 2♠ | 6 | 5–10 |
| 3♣ | 7 | 5–10 |
| 3♦ | 7 | 5–10 |
| 3♥ | 7 | 5–10 |
| 3♠ | 7 | 5–10 |
| 4♥ / 4♠ | 8 | 5–10 |

> **OBS:** **2♣ er IKKE en spærre.** 2♣ er den stærke kunstige åbning (22+ HP).

## Svar på makkeres spærremelding

```
Makker åbnede 2♥ (svag, 6♥, 5–10 HP)
│
├─ Svag hånd, ingen fit       → PAS
├─ 3+ ♥, svag hånd            → 3♥  (mere spærre, blokér yderligere)
├─ 4+ ♥, 16+ HP               → 4♥  (parti)
├─ Stærk uden fit             → 2NT (kunstig — spørger om kvalitet)
│       └─ Makker: 3 i åbningskuløren = svag kulør
│                  ny kulør = feature (A/K i sidekulør)
└─ Stærk, vil til slem        → 4NT (Blackwood)
```
